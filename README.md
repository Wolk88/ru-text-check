# ru-text-check

Скилл для нейросети: проверяет русский текст на логику, манипуляции и следы генерации и умеет переписать его по-человечески. Сделал для себя, теперь выкладываю для коллег.

Работает в Codex и Claude Code, формат скиллов у них общий.

## Установка

Codex на macOS:
```
git clone https://github.com/Wolk88/ru-text-check.git ~/.agents/skills/ru-text-check
```

Codex на Windows (PowerShell):
```
git clone https://github.com/Wolk88/ru-text-check.git $HOME\.agents\skills\ru-text-check
```

Claude Code:
```
git clone https://github.com/Wolk88/ru-text-check.git ~/.claude/skills/ru-text-check
```

После установки перезапустите приложение. Можно и проще: дать нейросети ссылку на этот репозиторий и попросить установить скилл.

## Как пользоваться

Отдельной команды не нужно. Пишете «проверь текст» или «очеловечь» и вставляете текст.

Проверка выдаёт отчёт с находками и исправленный вариант. Очеловечивание сразу переписывает текст и коротко перечисляет, что поменяно.

Придумывать факты за автора скиллу запрещено. Если для правки чего-то не хватает, в тексте появится пометка `[?: что именно]`, её заполняете сами.

## Откуда правила

Каталог признаков в `ai-patterns-ru.md` основан на эссе русской Википедии «Признаки сгенерированности текста» (ВП:ПРГЕН), примеры переписаны под рабочие тексты.
